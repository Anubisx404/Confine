# Confine Design Context

## Design Context

### Users
Software engineers exploring unfamiliar, polyglot, or large codebases on desktop workstations. They use Confine during architecture onboarding, code archaeology, refactoring audits, and search-driven navigation—expecting high information density, immediate keyboard responsiveness, and zero visual fluff.

### Brand Personality
**fast, dense, unimpressed**

Confine behaves like a logic analyzer or hardware profiler rather than a consumer dashboard. It communicates through crisp spatial geometry, exact tabular figures, and unadorned structural typography.

### Aesthetic Direction
- **Visual Tone**: Precision spatial profiling workstation modeled on Makepad Scope—hairline `1px` partitions, flat recessed surfaces, compact typographic ledgers, and high-contrast monospace telemetry.
- **Theme & Color System (OKLCH Industrial Graphite & Warm Ochre)**:
  - Canvas background: `oklch(0.155 0.005 245)`
  - Panel surface: `oklch(0.185 0.006 245)`
  - Elevated control / hover surface: `oklch(0.225 0.007 245)`
  - Hairline border: `oklch(0.285 0.008 245)`
  - Primary off-white ink: `oklch(0.925 0.006 85)`
  - Secondary / muted ink: `oklch(0.68 0.008 245)` / `oklch(0.52 0.008 245)`
  - Signal accent (warm ochre): `oklch(0.76 0.14 72)` paired with dark ink `oklch(0.16 0.01 72)` on active controls.
- **Typography**:
  - UI voice: `"Atkinson Hyperlegible", "Chivo", "Segoe UI Variable Text", "Segoe UI", sans-serif`
  - Telemetry / Code / Path voice: `"Commit Mono", "Iosevka", "Cascadia Mono", Consolas, monospace` with `font-variant-numeric: tabular-nums`.
- **Anti-References**: Generic dark SaaS dashboards, neon cyan-on-black AI themes, purple gradients, glowing box-shadows, rounded KPI metric cards, pill badges, and modal dialogs where inline workspace drawers belong.

### Design Principles
1. **Hairline Structure Over Containers**: Partition workspace panes, drawers, and inspector sections with `1px` solid rules (`2px` max radius) rather than nested cards or shadows.
2. **Typographic Ledger Over KPI Grids**: Present file and directory telemetry in tight, scannable inline tabular lines (`line N`, `X source lines · Y total · Z bytes`, `C children · D descendants`) rather than boxed metric cards.
3. **Inline Non-Modal Utility Drawers**: Keep disk navigation (`Dirs`) and exclusion rules (`Excludes`) as collapsible strips directly beneath the main toolbar so the spatial map remains visible while configuring scope.
4. **Restrained Signal Discipline**: Reserve warm ochre (`oklch(0.76 0.14 72)`) strictly for active state, focus outlines, search highlights, and primary action triggers.
5. **Zero-Friction Keyboard & Pointer Ergonomics**: Support direct shortcuts (`/`, `Ctrl+K`, `2`, `3`, `M`, `F`, `R`, `X` to exclude, `Alt+Left/Right` for history, `Esc` to dismiss drawers/inputs) without obscuring the canvas.
